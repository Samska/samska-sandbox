# Self-hosted fonts

Archivo (variable, Latin subset) and IBM Plex Mono 400, 500 and 600 (Latin subset), downloaded from Google Fonts and served from this origin so the Content-Security-Policy needs no external hosts and no request leaves the site. Both families are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org). `fonts.css` declares the faces.
